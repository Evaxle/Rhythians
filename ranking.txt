================================================
  RHYTHIANS RANKED SYSTEM — FULL REFERENCE
================================================

Rhythians uses Rhythian Points (RHP). Your rank is determined by your RHP.
There are 9 ranks, with the first 8 split into 5 tiers of 100 RHP each.

------------------------------------------------
1. THE RANKS
------------------------------------------------

  RANK      RHP RANGE        MAP RATING RANGE
  Copper    0     - 500      0.00 - 1.09
  Bronze    501   - 1000     1.10 - 1.49
  Silver    1001  - 1500     1.50 - 1.89
  Gold      1501  - 2000     1.90 - 2.29
  Platinum  2001  - 2500     2.30 - 2.69
  Emerald   2501  - 3000     2.70 - 2.99
  Diamond   3001  - 3500     3.00 - 3.29
  Master    3501  - 4000     3.30 - 3.69
  Expert    4001+            3.70 - 9.99

Expert begins at 3.70. The Rhythia-to-Rhythians conversion remains exactly:

  Rhythians rating = Rhythia stars x 0.41

rounded to two decimals.

Examples:
  5.00 stars = 2.05 rating
  8.00 stars = 3.28 rating
  9.00 stars = 3.69 rating
  9.03 stars = 3.70 rating

Therefore 9.00 stars is still Master, while the first Expert maps begin
when the converted rating reaches 3.70.

Each rank may only earn RHP from maps inside that rank's rating range.
Playing a map outside the player's current rank range earns no RHP.

Submitters suggest a rating when submitting a map. The reviewer confirms or
overrides the final rating, and the approved reviewer rating is authoritative.

------------------------------------------------
2. RHP GAIN
------------------------------------------------

RHP is calculated from four factors:

  1. The map's position inside the player's current rank range.
  2. The map's length.
  3. Accuracy.
  4. Speed modifier.

The same reward range is used for every rank. A map at the bottom of a rank
starts at the same base RHP as a map at the bottom of every other rank.
A harder map inside the same rank pays more.

The rating position is normalized separately for the player's rank:

  position = clamp((rating - rankMin) / (rankMax - rankMin), 0, 1)
  difficultyFactor = position ^ 0.9

The base reward is:

  baseRHP = 16.5 + (21 - 16.5) x difficultyFactor

This means every rank uses the same difficulty-to-RHP curve. A 4.00 Diamond
map is at the bottom of Diamond and therefore has the same base difficulty
reward as a 4.50 Master map at the bottom of Master. A 4.49 Diamond map is
worth more because it is near the top of Diamond.

At roughly 3 minutes, a 1.00-rated Copper map is around 20 RHP before
accuracy and speed modifiers.

------------------------------------------------
3. MAP LENGTH
------------------------------------------------

Three minutes is the reference length.

  lengthMultiplier = 0.75 + 0.25 x sqrt(lengthSeconds / 180)

The multiplier is clamped between 0.70 and 1.35.

The square-root curve makes longer maps worth more without allowing very long
maps to dominate the ladder.

Examples:
  30 seconds  -> about 0.85x
  1 minute    -> about 0.89x
  3 minutes   -> 1.00x
  5 minutes   -> about 1.07x
  10 minutes  -> about 1.34x

------------------------------------------------
4. ACCURACY
------------------------------------------------

  100%+ -> 1.00x
  99%+  -> 0.90x
  98%+  -> 0.75x
  95%+  -> 0.60x
  90%+  -> 0.50x
  <90%  -> 0.40x

------------------------------------------------
5. SPEED
------------------------------------------------

Speed above 1.00x grants a bonus:

  speedMultiplier = min(1.5, 1 + (speed - 1) x 0.25)

Normal speed receives no bonus. The speed bonus is capped at 1.50x.

------------------------------------------------
6. FINAL RHP
------------------------------------------------

  RHP = round(baseRHP x lengthMultiplier x accuracyMultiplier x speedMultiplier)

The minimum awarded amount is 5 RHP.

The rank range controls eligibility and the normalized position controls the
map's difficulty reward. Rank names themselves do not make maps worth more.

------------------------------------------------
7. RHP LOSS
------------------------------------------------

Failing a challenge map uses the existing placement-based loss system:

  baseLoss = max(5, round(rating x 10))
  loss = round(baseLoss x (yourPlace - 1) / totalBeaters)

RHP cannot fall below zero.
